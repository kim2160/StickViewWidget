# StickViewWidget v0.1

EdgeTX 컬러 스크린 조종기용 스틱/스로틀 모니터 위젯입니다.

## 기능
- 좌/우 박스에 스틱 위치(점) 표시
- 풀 스로틀 누적 시간 표시
- 평균 스로틀 퍼센트 표시(0% 제외 샘플)
- 옵션 화면 열 때 통계 리셋

## 옵션
- DotSize: 도트 크기
- BgColor: 배경 색
- DotColor: 도트/선 색

## 사용
`main.lua`를 위젯 폴더에 넣고, 위젯 추가 후 옵션을 설정하세요.

## 설치 경로 (EdgeTX)
일반적으로 아래 위치에 위젯 폴더를 둡니다.
- `/WIDGETS/StickView/` 에 `main.lua`
